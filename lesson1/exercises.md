# Упражнения к Lesson 1: Введение в ИИ-агенты и основы

## Упражнение 1: Сравнение чат-бота и ИИ-агента

### Цель
Понять ключевое различие между чат-ботом и ИИ-агентом.

### Задание
1. Представьте, что у вас есть задача: "Найди мне лучший отель в Париже на следующую неделю, забронируй его и отправь подтверждение на email."

2. Опишите, как бы эту задачу выполнил:
   - **Чат-бот**: Статичная система, ждущая вашего запроса
   - **ИИ-агент**: Автономная система, способная действовать

3. Ответьте на следующие вопросы:
   - Может ли чат-бот сам выполнить бронирование?
   - Может ли ИИ-агент самостоятельно планировать свои действия?
   - Что может сделать ИИ-агент, что недоступно чат-боту?

### Ответы (для самопроверки)
<details>
<summary>Развернутые ответы</summary>

**Чат-бот**:
- Ждет, когда вы скажете ему искать отель
- Отвечает на ваш запрос, но не может действовать вне диалога
- Не может сам выполнить бронирование или отправить email
- Его работа заканчивается на генерации ответа

**ИИ-агент**:
- Принимает задачу как цель
- Самостоятельно планирует действия: поиск → сравнение → бронирование → уведомление
- Может использовать инструменты (API для бронирования, email-клиент)
- Мониторит процесс и корректирует действия при необходимости

**Ключевое отличие**: Чат-бот отвечает, агент — действует.

</details>

## Упражнение 2: Проектирование простой архитектуры агента

### Цель
Практически применить знания об архитектуре ИИ-агента.

### Задание
Спроектируйте простого ИИ-агента для выполнения следующей задачи: "Проверь погоду в вашем городе на завтра и напиши краткий прогноз в формате: 'Завтра в Москве ожидается 15°C, дождь'".

Разбейте архитектуру на компоненты:

1. **Мозг (LLM)**: Какую роль будет выполнять?
2. **Инструменты**: Какие инструменты ему понадобятся?
3. **Память**: Нужна ли память для этой задачи?
4. **Планировщик**: Какие шаги включает план?

### Формат ответа
Создайте файл `agent_architecture.py` с описанием архитектуры:

```python
"""
Архитектура агента для проверки погоды
"""

# 1. Мозг (LLM)
brain = {
    "role": "Интерпретатор задачи и координатор",
    "function": "Принимает задачу, планирует действия, анализирует результаты, формирует ответ"
}

# 2. Инструменты
tools = [
    {
        "name": "get_weather",
        "description": "Получает текущую и прогнозную погоду для указанного города",
        "parameters": {"city": "название города"},
        "returns": "объект с температурой, осадками и другими параметрами"
    }
]

# 3. Память
memory = {
    "type": "краткосрочная",
    "purpose": "хранение контекста текущего запроса",
    "needs": "не требуется для этой задачи (одноразовая задача)"
}

# 4. Планировщик
planner = [
    "1. Определить название города из задачи",
    "2. Вызвать инструмент get_weather с названием города",
    "3. Проанализировать полученные данные о погоде",
    "4. Сформировать ответ в требуемом формате"
]
```

## Упражнение 3: Анализ цикла Восприятие-Мышление-Действие

### Цель
Понять, как работает цикл "Восприятие – Мышление – Действие" на практике.

### Задание
Представьте, что вы создаете ИИ-агента для решения задачи: "Найди в интернете последние новости о вашем любимом актере и подведи итоги".

Разбейте выполнение задачи на циклы "Восприятие – Мышление – Действие":

1. **Первый цикл**: 
   - Восприятие: ?
   - Мышление: ?
   - Действие: ?

2. **Второй цикл**:
   - Восприятие: ?
   - Мышление: ?
   - Действие: ?

И так далее, пока задача не будет выполнена.

### Пример заполнения:
```
Цикл 1:
- Восприятие: Получена задача "Найди последние новости о Леонардо Ди Каприо"
- Мышление: Нужно использовать инструмент поиска для нахождения новостей
- Действие: Вызов инструмента поиска с запросом "новости Леонардо Ди Каприо"

Цикл 2:
- Восприятие: Результаты поиска с URL новостей
- Мышление: Нужно открыть несколько новостных сайтов и извлечь ключевую информацию
- Действие: Вызов инструмента скрапинга для каждого найденного URL

Цикл 3:
- Восприятие: Тексты с новостных сайтов
- Мышление: Анализ текстов, выделение ключевых событий, формирование резюме
- Действие: Генерация итогового отчета
```

## Упражнение 5: Сравнительный анализ

### Цель
Закрепить понимание различий между подходами к автоматизации.

### Задание
Сравните следующие подходы к выполнению задачи "Написать отчет по продажам":

1. **Ручной подход**: Человек делает всё сам
2. **Скрипт/автоматизация**: Предопределенная программа с жесткими правилами
3. **Чат-бот**: Отвечает на запросы, но не действует автономно
4. **ИИ-агент**: Автономный агент с циклом "Мышление-Действие"

Для каждого подхода оцените по шкале от 1 до 5:
- Гибкость (1 - жестко заданные действия, 5 - полностью адаптивные)
- Автономность (1 - постоянное присутствие человека, 5 - полностью самостоятельный)
- Сложность задач (1 - простые, 5 - сложные, неструктурированные)
- Возможность обучения (1 - не обучается, 5 - может учиться на опыте)
