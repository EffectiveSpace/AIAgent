## Упражнение 6: Работа с инструментами в LangChain

### Цель

### Задание

### Требования

### Пример
```python

from langchain_openai import ChatOpenAI
from langchain import hub
from langchain.agents import create_react_agent, AgentExecutor

@tool
def custom_weather_tool(city: str) -> str:
    """Инструмент для получения погоды."""
    # Ваша реализация
    return f"Погода в {city}:..."

# Создаем LLM

# Получаем промпт для ReAct

# Создаем агента
```

## Упражнение 7: Оптимизация инструментов

### Цель
Научиться оптимизировать инструменты для более эффективной работы агента.

### Задание
Для одного из созданных инструментов реализуйте:
1. Кэширование результатов (если возможно)
2. Ограничение количества вызовов за единицу времени
3. Валидацию входных данных
4. Логирование вызовов

### Пример реализации кэширования
```python
from functools import lru_cache
import time

class CachedTool:
    def __init__(self):
        self.call_log = []
        self.call_limit = 10  # максимум 10 вызовов в минуту
    
    @lru_cache(maxsize=128)
    def cached_web_search(self, query: str) -> str:
        # Проверяем лимиты
        self.check_rate_limit()
        # Добавляем в лог
        self.log_call(query)
        # Выполняем поиск
        return self._perform_search(query)
    
    def check_rate_limit(self):
        now = time.time()
        # Убираем вызовы старше 60 секунд
        self.call_log = [call_time for call_time in self.call_log if now - call_time < 60]
        if len(self.call_log) >= self.call_limit:
            raise Exception("Превышен лимит вызовов инструмента")
    
    def log_call(self, query: str):
        self.call_log.append(time.time())
```
