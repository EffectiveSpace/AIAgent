## Упражнение 4: Сравнение разных подходов к планированию

### Цель
Понять различия между подходами к декомпозиции задач.

### Задание
Реализуйте два разных подхода к планированию для одной и той же задачи:

**Задача**: "Планирование путешествия в Париж на 3 дня"

**Подход 1: Прямое планирование**
- Сначала создается полный план
- Потом план пошагово исполняется

**Подход 2: Адаптивное планирование (ReAct)**
- На каждом шаге принимается решение, что делать дальше
- План может меняться в зависимости от обстоятельств

### Сравнение
Для каждого подхода:
1. Реализуйте симуляцию
2. Оцените:
   - Надежность (что произойдет при сбое?)
   - Адаптивность (как реагирует на изменения?)
   - Сложность реализации
   - Прозрачность (насколько понятен процесс?)

### Вопросы
1. В каких случаях лучше использовать каждый подход?
2. Какие задачи подходят только для адаптивного планирования?
3. Могут ли оба подхода быть использованы в одном агенте?

## Упражнение 5: Реализация простой памяти

### Цель
Понять, как работает память на практике и почему она важна.

### Задание
Реализуйте три разных механизма памяти для агента:

1. **Краткосрочная память (ограниченный контекст)**:
   - Ограничьте количество сообщений в истории диалога
   - Реализуйте FIFO (first-in-first-out) или LIFO (last-in-first-out) стратегию

2. **Долгосрочная память (на основе ключевых слов)**:
   - Сохраняйте важные фрагменты разговора с тегами
   - Реализуйте поиск по тегам или ключевым словам

3. **Гибридная память**:
   - Соедините оба подхода
   - Некоторая информация в краткосрочной памяти, другая - в долгосрочной

### Тестирование
Создайте симуляцию разговора с несколькими темами и проверьте, как каждый тип памяти справляется:
- "Привет! Меня зовут Алекс. Я программист. Какой сегодня день? Какие курсы ты рекомендуешь программисту? Кстати, как меня зовут?"

### Вопросы для анализа
1. Какой тип памяти лучше подходит для долгих разговоров?
2. Какой тип памяти дешевле в использовании?
