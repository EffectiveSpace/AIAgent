## Упражнение 1: Подключение к разным LLM API

### Цель
Практически подключиться к API различных LLM и сравнить их поведение.

### Задание
1. Установите необходимые библиотеки:
```bash

```

2. Создайте файл `.env` с вашими API-ключами:
```

ANTHROPIC_API_KEY="ваш_ключ_от_anthropic"
GOOGLE_API_KEY="ваш_ключ_от_google"
```

3. Создайте Python-скрипт, который отправляет один и тот же запрос всем трем моделям:
   - GPT-3.5-turbo от OpenAI
   - Claude-3-haiku от Anthropic
   - Gemini Pro от Google

4. Сравните:
   - Время ответа
   - Стиль ответа
   - Длину ответа
   - Качество рассуждений

### Код для заполнения
```python
import os
import time
from openai import OpenAI
from dotenv import load_dotenv

# Загрузка переменных окружения
load_dotenv()

# Инициализация клиента OpenAI
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# Отправка запроса
start_time = time.time()
response = client.chat.completions.create(
    model="gpt-3.5-turbo",  # Замените на другие модели для сравнения
    messages=[
        {"role": "system", "content": "Ты — помощник, объясняющий концепции программирования."},
        {"role": "user", "content": "Объясни, что такое цикл for в Python простыми словами."}
    ]
)
end_time = time.time()

print(f"Время ответа: {end_time - start_time:.2f} сек.")
print(f"Ответ: {response.choices[0].message.content}")
```

## Упражнение 3: Работа с токенами

### Цель
Понять, как измеряются и считаются токены, и как они влияют на стоимость.

### Задание
1. Установите библиотеку для подсчета токенов:
```bash
pip install tiktoken
```

2. Создайте скрипт, который считает токены в различных текстах:

```python
import tiktoken

# Используем энкодер для GPT-4 (cl100k_base)
encoding = tiktoken.get_encoding("cl100k_base")

# Тестовые тексты
texts = [
    "Привет мир!",
    "Это немного более длинный текст с несколькими словами.",
    "Длинный текст может содержать много токенов. Каждое слово, каждый символ и даже пробелы могут быть учтены в подсчете токенов. В русском языке слова часто разбиваются на части, что увеличивает количество токенов.",
    "Python - это мощный язык программирования. Он используется для создания веб-приложений, анализа данных, машинного обучения и многого другого. Python имеет простой и понятный синтаксис, что делает его отличным выбором для новичков."
]

for i, text in enumerate(texts):
    tokens = encoding.encode(text)
    print(f"Текст {i+1}: {len(tokens)} токенов")
    print(f"Текст: {text[:50]}...")
    print("---")
```

3. Затем посчитайте токены в системном промпте и сообщении пользователя:

```python
# Системный промпт
system_prompt = "Ты — помощник по программированию. Отвечай кратко и точно, используя примеры кода."

# Пользовательский запрос
user_message = "Напиши функцию, которая сортирует массив чисел по возрастанию."

# Подсчитайте токены для каждого
system_tokens = encoding.encode(system_prompt)
user_tokens = encoding.encode(user_message)

print(f"Системный промпт: {len(system_tokens)} токенов")
print(f"Пользовательское сообщение: {len(user_tokens)} токенов")
print(f"Всего на вход: {len(system_tokens) + len(user_tokens)} токенов")
```

### Анализ стоимости
Используя данные о стоимости API (из урока), рассчитайте приблизительную стоимость одного запроса.
