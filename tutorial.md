# Урок 1: Настройка Ollama для работы с ИИ-агентами

## Введение

Ollama - это инструмент, который позволяет легко настроить и запустить большие языковые модели (LLM) на вашем локальном компьютере. Это отличная альтернатива облачным API, так как позволяет работать с ИИ-моделями автономно, без передачи данных в интернет.

## Установка Ollama

1. **Скачивание Ollama**
   - Перейдите на официальный сайт: https://ollama.ai
   - Скачайте подходящую версию для вашей операционной системы (Windows, macOS или Linux)

2. **Установка**
   - Для Windows: запустите установочный файл и следуйте инструкциям мастера установки
   - Для macOS: используйте Homebrew или установите через загруженный .pkg файл
   - Для Linux: выполните команду в терминале:
   ```bash
   curl -fsSL https://ollama.ai/install.sh | sh
   ```

3. **Запуск Ollama**
   - После установки Ollama должен автоматически запустить фоновый сервис
   - Проверьте статус службы через команду:
   ```bash
   ollama serve
   ```
   - Эта команда запустит сервер Ollama, который будет прослушивать порт 11434

## Запуск моделей с помощью Ollama

1. **Список доступных моделей**
   Посетите https://ollama.ai/library для просмотра списка доступных моделей

2. **Установка и запуск модели**
   ```bash
   # Запуск конкретной модели (например, llama2)
   ollama run llama2
   
   # Или другая популярная модель
   ollama run mistral
   ```

3. **Проверка установленных моделей**
   ```bash
   ollama list
   ```

## Настройка Python для работы с Ollama

Для взаимодействия с Ollama из Python можно использовать библиотеку `requests`:

```python
import requests
import json

def query_ollama(prompt, model="llama2"):
    url = "http://localhost:11434/api/generate"
    data = {
        "model": model,
        "prompt": prompt,
        "stream": False
    }
    
    response = requests.post(url, json=data)
    if response.status_code == 200:
        result = response.json()
        return result.get('response', '')
    else:
        return f"Ошибка: {response.status_code}"

# Пример использования
result = query_ollama("Привет! Расскажи о себе кратко.")
print(result)
```


## Оптимизация производительности

- Ollama автоматически определяет и использует GPU при его наличии
- Для улучшения производительности рекомендуется иметь не менее 8 ГБ ОЗУ
- Некоторые крупные модели могут требовать 16 ГБ ОЗУ или больше

## Возможные проблемы и их решение

1. **Ошибка подключения**
   - Убедитесь, что сервер Ollama запущен (ollama serve)
   - Проверьте, что порт 11434 не занят другими приложениями

2. **Загрузка модели не завершается**
   - Проверьте подключение к интернету
   - Модели могут быть большими (от 2 до 15+ ГБ), требуется время на загрузку

3. **Низкая производительность**
   - Проверьте использование ЦП и ОЗУ
   - Рассмотрите возможность использования моделей меньшего размера

## Заключение

Установка и настройка Ollama является важным первым шагом для локальной разработки ИИ-агентов. После успешной настройки вы сможете экспериментировать с различными моделями, не завися от интернет-соединения или облачных API.
