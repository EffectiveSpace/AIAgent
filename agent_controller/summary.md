## Введение

Этот курс посвящен созданию системы управления микроконтроллером Arduino с помощью ИИ-агента Ollama. В ходе курса вы научитесь создавать замкнутую систему, в которой ИИ-агент может:
- Интерпретировать команды на естественном языке
- Преобразовывать команды в протокольные сообщения для Arduino
- Получать и анализировать данные с датчиков
- Принимать решения на основе машинного обучения
- Управлять физическими устройствами (светодиоды, сервоприводы и др.)

Курс состоит из 5 уроков, каждый из которых постепенно усложняет систему и добавляет новые функции.

## Лекции и практические задания

### Урок 1: Введение в управление микроконтроллерами с помощью ИИ-агента Ollama

**Цель урока**: Научиться устанавливать связь между ИИ-агентом Ollama и микроконтроллером Arduino UNO с использованием протокола связи, рассмотренного в туториале.

**Основные темы**:
- Основы протокола связи между компьютером и Arduino
- Структура пакета: [SYNC1, SYNC2, LEN_DATA, DATA..., CRC]
- Использование FSM (конечного автомата) для обработки пакетов
- Настройка базовой системы связи

**Практическое задание**:
1. Установите Ollama на ваш компьютер
2. Загрузите код в Arduino UNO
3. Подключите Arduino к компьютеру и определите правильный COM-порт

## Протокол связи

Система использует следующую структуру пакета:
```
[SYNC1, SYNC2, LEN_DATA, DATA..., CRC]
```

Где:
- `SYNC1` (0xAA) - начальный байт синхронизации
- `SYNC2` (0x55) - дополнительный байт синхронизации
- `LEN_DATA` - количество байт данных
- `DATA` - полезные данные (команды и параметры)
- `CRC` - контрольная сумма

Команды Arduino:
- `CMD_LED_ON` (0x01) - включить светодиод
- `CMD_LED_OFF` (0x02) - выключить светодиод
- `CMD_LED_BLINK` (0x03) - мигнуть светодиодом
- `CMD_GET_SENSOR` (0x04) - получить данные сенсора
- `CMD_SERVO_ANGLE` (0x05) - установить угол сервопривода
- `CMD_GET_SERVO_ANGLE` (0x06) - получить текущий угол сервопривода
- `CMD_GET_TEMPERATURE` (0x07) - получить температуру
- `CMD_GET_LIGHT` (0x08) - получить уровень освещенности
- `CMD_GET_ALL_SENSORS` (0x09) - получить все сенсорные данные
- `CMD_AUTO_MODE` (0x0A) - включить/выключить автоматический режим

## Два способа взаимодействия с Ollama

В курсе представлены два подхода к взаимодействию с Ollama:

### 1. Локальная установка Ollama (рекомендуемый подход)
- Установка Ollama на локальный компьютер
- Использование библиотеки `ollama` для прямого взаимодействия
- Преимущества:
  - Лучшая производительность
  - Надежность (не зависит от интернета)
  - Приватность (данные не покидают компьютер)
  - Меньше задержек

**Пример инициализации:**
```python
interface = AI_Arduino_Interface('COM3', use_local_ollama=True, model="llama3")
```

### 2. HTTP API
- Взаимодействие через HTTP-запросы к API Ollama
- Подходит для удаленных серверов или облачных решений
- Преимущества:
  - Гибкость размещения
  - Возможность масштабирования

**Пример инициализации:**
```python
interface = AI_Arduino_Interface('COM3', use_local_ollama=False, ollama_url="http://localhost:11434/api/generate", model="llama2")
```
