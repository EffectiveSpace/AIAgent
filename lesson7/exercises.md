### Пример реализации для фиксированного размера
```python
def fixed_chunking(text: str, chunk_size: int = 512, overlap: int = 50):
    """
    Разбивает текст на фиксированные чанки.
    """
    words = text.split()
    chunks = []
    for i in range(0, len(words), chunk_size - overlap):
        chunk = ' '.join(words[i:i+chunk_size])
        chunks.append(chunk)
    return chunks
```

## Упражнение 4: Реализация паттерна RAG с кэшированием

### Цель
Улучшить производительность системы RAG с помощью кэширования результатов поиска.

### Задание
Реализуйте систему RAG, которая:
1. Перед выполнением поиска проверяет, не был ли уже выполнен аналогичный запрос
2. Кэширует результаты поиска (найденные документы и Embeddings)
3. Обновляет кэш с течением времени

### Пример реализации
```python
import hashlib
from datetime import datetime, timedelta

class CachedRAGSystem:
    def __init__(self, cache_ttl_minutes=60):
        self.cache = {}
        self.ttl = timedelta(minutes=cache_ttl_minutes)
    
    def get_cache_key(self, query_text):
        """Создает уникальный ключ для запроса."""
        return hashlib.md5(query_text.encode()).hexdigest()
    
    def is_cached(self, cache_key):
        """Проверяет, есть ли результат в кэше и не просрочен ли он."""
        if cache_key in self.cache:
            timestamp, _ = self.cache[cache_key]
            return datetime.now() - timestamp < self.ttl
        return False
    
    def cache_result(self, cache_key, result):
        """Сохраняет результат в кэш."""
        self.cache[cache_key] = (datetime.now(), result)
    
    def search_with_cache(self, query_text):
        """Выполняет поиск с кэшированием."""
        cache_key = self.get_cache_key(query_text)
        
        if self.is_cached(cache_key):
            _, cached_result = self.cache[cache_key]
            print("Результат взят из кэша")
            return cached_result
        else:
            print("Выполняется новый поиск")
            # Выполнить реальный поиск в векторной базе
            result = self.perform_real_search(query_text)
            self.cache_result(cache_key, result)
            return result
```

## Упражнение 6: Построение RAG-агента с использованием LangChain

### Цель
Использовать готовый фреймворк для реализации системы RAG.

### Задание
Используйте LangChain для создания RAG-агента:
- Загрузите документы с помощью LangChain Document Loaders
- Используйте Text Splitters для чанкинга
- Создайте векторное хранилище
- Используйте RetrievalQA для построения цепочки RAG

### Пример кода
```python
from langchain.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.embeddings import HuggingFaceEmbeddings
from langchain.vectorstores import Chroma
from langchain.chains import RetrievalQA
from langchain_openai import ChatOpenAI

# 1. Загрузка документов
loader = TextLoader("path/to/document.txt")
documents = loader.load()

# 2. Разделение на чанки
text_splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200)
docs = text_splitter.split_documents(documents)

# 3. Создание эмбеддингов
embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")

# 4. Создание векторного хранилища
db = Chroma.from_documents(docs, embeddings)

# 5. Создание retriever
retriever = db.as_retriever()

# 6. Создание LLM
llm = ChatOpenAI(model="gpt-3.5-turbo")

# 7. Создание RAG цепочки
qa = RetrievalQA.from_chain_type(
    llm=llm, 
    chain_type="stuff", 
    retriever=retriever
)

# 8. Задание вопроса
result = qa.invoke({"query": "Ваш вопрос"})
```
