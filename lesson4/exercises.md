## Упражнение 3: Техника Chain-of-Thought (CoT)

### Цель
Понять, как техника CoT улучшает логику и точность агента.

### Задание
Создайте 3 задачи, требующие логических рассуждений, и сравните результаты с применением и без применения CoT.

### Пример задачи:
"У Дарьи есть 3 брата. У каждого брата по одной сестре. Сколько детей в семье Дарьи?"

#### Вариант без CoT:
```
Сколько детей в семье Дарьи?
```

#### Вариант с CoT:
```
Сколько детей в семье Дарьи? Подумай шаг за шагом, рассуждай вслух, затем дай ответ.
```

### Задание
1. Придумайте 3 логические задачи
2. Для каждой создайте два варианта запроса (с CoT и без)
3. Сравните результаты 
4. Проанализируйте, почему CoT помогает

### Анализ
- В каких случаях CoT дает наибольшую пользу?
- Какие типы задач лучше всего подходят для CoT?
- Есть ли задачи, где CoT может быть избыточным?

## Упражнение 4: Техника Tree-of-Thought (ToT) - теоретическое упражнение

### Цель
Понять концепцию ToT и когда она применима.

### Задание
Рассмотрите следующую сложную задачу и разбейте её на дерево возможных подходов:

**Задача**: "Какую карьерную стратегию выбрать человеку с опытом в маркетинге, который хочет перейти в ИИ?"

### Этапы ToT:
1. **Определение шагов**: Какие основные этапы нужно пройти для решения задачи?
2. **Генерация мыслей**: Для каждого этапа сгенерируйте 3-5 возможных подходов
3. **Оценка**: Как оценить перспективность каждого подхода?
4. **Выбор**: Как выбирать между несколькими подходами?

### Практическое задание
Создайте псевдокод или диаграмму логики, которая реализует ToT-подход для этой задачи:
- Пользователь задает вопрос
- Агент генерирует несколько возможных стратегий
- Агент оценивает каждую стратегию
- Агент выбирает наилучшую и детализирует
